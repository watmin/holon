# Archived Scripts

These scripts are kept for historical reference but are not actively maintained.

## Directories

### legacy_tests/
Informal test scripts created during development. The formal test suite is in `tests/`.

Contains:
- `api/` - Early API tests (guards, negation, positional encoding, etc.)
- `integration/` - Integration test experiments
- `performance/` - Performance and stress test experiments

### rpm_debug/
Debug scripts created while working on RPM (Raven's Progressive Matrices) challenge.

### misc/
One-off scripts and misplaced test files:
- `test_new_api.py` - HTTP API test script
- `test_unified_client_http.py` - Client HTTP test
- `update_challenges_to_client.py` - Migration script (one-time use)
- `compare_tests.py` - Debug comparison script
- `simple_extended_test.py` - Extended test experiments
- `test_accuracy.py` - Accuracy testing script
